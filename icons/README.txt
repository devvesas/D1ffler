Code File Icons v3

Original monochrome SVG file-type icons generated for use in a PyQt file tree.

This version includes:
- Programming/source files
- Headers and scripts
- YAML, Dockerfile and Terraform
- TXT, RTF, PDF and CSV
- Microsoft Word / Excel / PowerPoint formats
- OpenDocument ODT / ODS / ODP
- Common image formats: JPEG, PNG, GIF, SVG, WebP, BMP, TIFF, ICO, HEIC/HEIF
- Common camera RAW formats

Notes:
- Dockerfile has no extension, so use FILENAME_ICON_MAP before extension lookup.
- These are generic/original file-type badges, not official product/language logos.
